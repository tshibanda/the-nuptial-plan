---
name: Mobile form dates
description: Project-wide rule for date entry in mobile forms.
---

All date fields in mobile forms should use a date selector rather than manual keyboard entry.

**Why:** The user requested date selection in every mobile form to make date entry easier and less error-prone.

**How to apply:** When creating or editing any mobile form with a date or month field, provide an appropriate date/month selector and keep the saved value in the format expected by the app.
